# 마감 임박 감시 (매주)

날짜가 지나면 사라지는 지원을 찾아, 남은 날이 얼마 없으면 캠페인 한 장을 만들어
띄우고 사장님께 알린다. 이 사이트에서 가장 값이 나가는 일이다. 금액을 정확히
알려주는 것보다 **끝나는 줄 몰라서 못 받는 일을 막는 쪽**이 사람들에게 크다.

## 1. 지금 걸려 있는 것부터 본다

```
rules/<연도>/deadlines.json   — 캠페인으로 만든 것들
```

- `dueAt`이 지난 항목은 지우지 않는다. 화면에서 알아서 빠진다(`statusOf().passed`).
  지워버리면 나중에 "작년에 그거 어떻게 됐지"를 확인할 길이 없어진다.
- 마감이 **45일 안**으로 들어온 것은 홈 띠와 사이트맵에 자동으로 뜬다.
  (`URGENT_WITHIN_DAYS`, `lib/calculators/deadlines.ts`)
- 남은 날이 **7일 이하**인데 아직 사장님께 안 알렸으면 이번에 알린다.

## 2. 새로 끝나는 것이 없는지 찾는다

이런 것들이 대상이다. 개인 조건과 무관하게 **달력을 보면 누구에게나 똑같이 끝나는 것**.

- 예산이 떨어져 중단되는 지자체 사업 (경기도 산후조리비가 그랬다)
- 한시 제도의 일몰 (결혼세액공제 2026-12-31)
- 연 단위로 신청 창구가 닫히는 것 (쉼 지원 5종, 스포츠강좌이용권)
- 소급 신청 기한이 걸린 것

찾는 곳:

- `rules/` 전체의 `applyHardDeadline`, `effectiveTo`, `applyDeadlineNote`
- `rules/2026/rest-benefits.json`의 신청 기간
- 지자체 공고·부처 보도자료 (블로그·카페는 실마리로만 쓴다)

## 3. 캠페인으로 만들 값어치가 있는지 가른다

전부 만들면 홈 띠가 배경이 되어 아무도 안 본다. 셋 다 맞아야 만든다.

1. **금액이 있다.** 얼마인지 말할 수 있어야 클릭한다. "지원합니다"로는 안 된다.
2. **남은 날이 45일 안이다.** 더 멀면 지금 알려도 잊어버린다.
3. **몰라서 못 받는 사람이 실제로 있다.** 자동 지급되는 것은 대상이 아니다.

## 4. 만든다

`rules/<연도>/deadlines.json`의 `items`에 한 덩어리를 넣으면 나머지는 자동이다.
페이지, 공유 이미지, 홈 띠, 사이트맵이 따라온다.

채울 때 지킬 것:

- `hook` — 링크만 봐도 누르게 만드는 한 줄. **지역과 금액과 날짜**가 들어가야 한다.
  ("경기도에서 아이 낳으셨어요? 9월 30일까지만 50만원 나옵니다")
- `hookShort` — 공유 이미지에 들어갈 짧은 판.
- `whyUrgent` — 왜 하필 지금인지. 여기가 비면 그냥 안내문이 된다.
- `who` — 읽는 사람이 자기가 해당되는지 3초 안에 가릴 수 있게.
- `watchOut` — 확인 못 한 것이 있으면 **여기 그대로 적는다.** 숨기지 않는다.
- `verifiedBy` — 무엇을 보고 확인했는지. 확인 못 한 것은 확인 못 했다고 쓴다.

그 다음:

```
node scripts/make-og.mjs      # 공유 이미지를 굽는다
npx tsc --noEmit && npx eslint . && npx vitest run && npx next build
```

전부 통과하면 `claude/brave-hypatia-6yewiq`와 `main` 양쪽에 푸시하고,
https://iamstillbaby.com/deadline/<slug> 가 200으로 뜨는지 확인한다.

## 5. 알린다

사장님께 이렇게 보고한다. 개발 용어 없이.

- 무엇이 언제 끝나는지, 얼마인지
- 누가 놓치게 되는지
- **만든 링크 주소** (바로 복사해서 보낼 수 있게)
- 공유하면 나가는 문구 그대로
- 확인 못 한 것이 있으면 그것도

바뀐 게 없으면 **한 줄로 끝낸다.** 없는 일을 지어내지 않는다.

## 경계

- 마감일은 **공식 안내로 확인한 것만** 쓴다. 확인 못 했으면 `watchOut`에 적고
  전화번호를 함께 둔다. 하루 차이로 돈이 갈리는 값이라 틀리면 그냥 틀린 게 아니다.
- 자극적으로 쓰지 않는다. 과장 없이 사실만으로도 충분히 급하다.
- 이미 끝난 것을 급한 것처럼 띄우지 않는다.
